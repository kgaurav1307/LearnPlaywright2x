## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (LTS recommended)
- [VS Code](https://code.visualstudio.com/)
- [Playwright](https://playwright.dev/)

### Installation

```bash
npm install
```

### Running Tests

```bash
npx playwright test
```
