# VS Code Keyboard Shortcuts — macOS

## General

| Action | Shortcut |
|--------|----------|
| Command Palette | `Shift + Cmd + P` / `F1` |
| Quick Open, Go to File... | `Cmd + P` |
| New file | `Cmd + N` |
| New window | `Shift + Cmd + N` |
| Open file... | `Cmd + O` |
| Open folder... | `Cmd + K` `Cmd + O` |
| Open recent... | `Ctrl + R` |
| Save | `Cmd + S` |
| Save As... | `Shift + Cmd + S` |
| Save All | `Option + Cmd + S` |
| Close file | `Cmd + W` |
| Close folder | `Cmd + K` `F` |
| Close window | `Cmd + W` |
| Cut | `Cmd + X` |
| Copy | `Cmd + C` |
| Paste | `Cmd + V` |
| Undo | `Cmd + Z` |
| Redo | `Shift + Cmd + Z` |
| Toggle Full Screen | `Ctrl + Cmd + F` |
| Show Explorer | `Shift + Cmd + E` |
| Show Search | `Shift + Cmd + F` |
| Show Source Control | `Ctrl + Shift + G` |
| Show Run and Debug | `Shift + Cmd + D` |
| Show Extensions | `Shift + Cmd + X` |
| Replace in files | `Shift + Cmd + H` |
| Toggle Search details | `Cmd + Shift + J` |
| Show Output panel | `Shift + Cmd + U` |
| Open Markdown preview | `Shift + Cmd + V` |
| Open Markdown preview to the side | `Cmd + K` `V` |
| Zen Mode | `Cmd + K` `Z` |
| Toggle center layout | `Cmd + K` `Shift + Enter` |
| Leave Zen Mode | `Escape` `Escape` |
| Close unmodified editors | `Cmd + K` `U` |
| Close all editors | `Cmd + K` `W` |
